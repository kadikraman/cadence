Check that a user can mark a task as done.

1. Finish onboarding as the app facts say.
2. Press the starter task "Water the plants, every 3 days" to add it. If a form opens, save it as it is. Check that "Water the plants" shows on the main screen. Save a screenshot.
3. Mark "Water the plants" as done today. Use the round check button on its row. If you cannot find it, swipe the row to the right and press "Done". Save a screenshot.
4. Check that the row shows the task as done, and that its due label changes to a later day. Save a screenshot.

Out of scope for this lane: do not delete or edit the task, and do not open Settings.

Pass condition: after you mark it done, the task shows as done and its next due day is later than before.
